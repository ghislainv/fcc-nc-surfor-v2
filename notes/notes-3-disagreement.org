*** J'ai des répétitions pour photo-interpréter des pixels forestiers ou non avec 3 photos-interprètes différents. Comme estimer un taux de désaccord ?

Bonne question méthodologique ! Pour estimer un *taux de désaccord* entre plusieurs interprètes sur une classification binaire (forestier / non-forestier), plusieurs approches existent :

---

** 1. 📊 Taux de désaccord brut (simple)

Pour chaque pixel, vérifier si les 3 interprètes sont unanimes ou non :

#+begin_src 
Taux de désaccord = Nbre de pixels avec au moins 1 désaccord / Nbre total de pixels
#+end_src

Simple, mais ne distingue pas les *degrés* de désaccord (1 contre 2 vs 3 avis différents).

---

** 2. 🎯 Kappa de Cohen (par paires)

Comparer les interprètes *deux à deux* (3 paires : A/B, A/C, B/C) :

#+begin_src 
κ = (P_o - P_e) / (1 - P_e)
#+end_src

- *P_o* = accord observé
- *P_e* = accord attendu par chance

| κ | Interprétation |
|---|---|
| < 0.20 | Très faible |
| 0.20–0.40 | Faible |
| 0.40–0.60 | Modéré |
| 0.60–0.80 | Bon |
| > 0.80 | Très bon |

---

** 3. 🏆 Kappa de Fleiss (≥ 3 interprètes simultanément)

C'est *l'extension naturelle* du Kappa de Cohen pour *k ≥ 3 évaluateurs* :

#+begin_src 
κ_Fleiss = (P̄ - P̄_e) / (1 - P̄_e)
#+end_src

Où P̄ est la proportion moyenne d'accord entre toutes les paires possibles. C'est probablement *la méthode la plus adaptée à votre cas*.

---

** 4. 📐 Krippendorff's Alpha

Plus général que Fleiss, gère :
- Les *données manquantes*
- Différents types de variables (nominale, ordinale, etc.)

Très robuste, recommandé si vos données sont incomplètes.

---

** 🔧 En pratique (R / Python)

*R :*
#+begin_src r
library(irr)
kappam.fleiss(data)   # Fleiss Kappa
kripp.alpha(data)     # Krippendorff Alpha
#+end_src

*Python :*
#+begin_src python

# ou

krippendorff.alpha(data)
#+end_src

---

** ✅ Recommandation

| Situation | Méthode conseillée |
|---|---|
| Vue d'ensemble rapide | Taux de désaccord brut |
| Comparaison par paires | Kappa de Cohen |
| *3 interprètes, données complètes* | *Kappa de Fleiss* ✅ |
| Données manquantes | Krippendorff's Alpha |

Krippendorff's Alpha est alors la solution idéale, car il gère nativement les *nombres d'évaluateurs variables* (2 ou 3 selon les pixels) ainsi que les données manquantes.

---

* 🏆 Krippendorff's Alpha — votre cas

Imaginez votre tableau de données comme :

| Pixel | Interprète A | Interprète B | Interprète C |
|-------|-------------|-------------|-------------|

| 2 | Forêt | Non-forêt | NA |
| 3 | Non-forêt | Non-forêt | Non-forêt |

Les =NA= sont gérés nativement — pas besoin de supprimer ces lignes.

Est-ce possible de calculer à la main sans passer par le package irr. Et peut-on calculer aussi le désaccord brut facile à expliquer.

Oui ! Voici les deux calculs à la main :

---

- 1. 📊 Désaccord brut

Un pixel est en désaccord si les interprètes ne sont *pas tous unanimes* :

#+begin_src r
desaccord_brut <- data_wide %>%
  rowwise() %>%
  mutate(
    valeurs    = list(na.omit(c_across(-c(plotid, sampleid)))),
    unanime    = length(unique(valeurs[[1]])) == 1,
    desaccord  = !unanime
  ) %>%
  ungroup() %>%
  summarise(
    n_pixels        = n(),
    n_desaccord     = sum(desaccord),
    taux_desaccord  = mean(desaccord)
  )

print(desaccord_brut)
#+end_src

Très facile à expliquer : /"X% des pixels n'ont pas reçu la même classification par tous les interprètes."/

---

- 2. 🏆 Krippendorff Alpha à la main

Pour des données *nominales*, la formule est :

#+begin_src 
α = 1 - (D_o / D_e)
#+end_src

- /D_o/ = désaccord observé
- /D_e/ = désaccord attendu par chance

#+begin_src r
# --- Préparer la matrice des interprètes uniquement ---
mat <- data_wide %>%
  select(-plotid, -sampleid) %>%
  as.matrix()

# --- Désaccord observé (D_o) ---
# Pour chaque pixel, on compte les paires en désaccord
do_pixel <- apply(mat, 1, function(row) {
  vals <- na.omit(row)
  n <- length(vals)
  if (n < 2) return(NA)
  # Nombre de paires en désaccord sur total de paires
  paires_desaccord <- sum(outer(vals, vals, "!=")) / 2
  paires_total     <- n * (n - 1) / 2
  paires_desaccord / paires_total
})

D_o <- mean(do_pixel, na.rm = TRUE)

# --- Désaccord attendu par chance (D_e) ---
# Fréquence de chaque classe sur l'ensemble des annotations
toutes_vals <- na.omit(as.vector(mat))
n_total     <- length(toutes_vals)
freq        <- table(toutes_vals) / n_total

# D_e = 1 - somme(freq_k^2)  [proba que 2 annotations tirées au hasard diffèrent]
D_e <- 1 - sum(freq^2)

# --- Alpha ---
alpha <- 1 - (D_o / D_e)

cat("Désaccord observé  (D_o) :", round(D_o,  4), "\n")
cat("Désaccord attendu  (D_e) :", round(D_e,  4), "\n")
cat("Krippendorff Alpha       :", round(alpha, 4), "\n")
#+end_src

---

- 🔑 Interprétation combinée

| Métrique | Ce qu'elle mesure | Facile à expliquer ? |
|---|---|---|
| Désaccord brut | % pixels non unanimes | ✅ Très facile |
| Krippendorff α | Désaccord au-delà du hasard | ⚠️ Necessite explication |

Les deux sont complémentaires : le désaccord brut pour communiquer, l'alpha pour la rigueur statistique !

Comment distinguer si un des interpreteurs est mauvais. Répondre en anglais.

Good question! Here are several approaches to identify if one interpreter is systematically different from the others:

---

/1. 📊 Pairwise agreement (simple)/

Compare each pair of interpreters directly :

#+begin_src r
library(dplyr)
library(tidyr)

# Get interpreter emails
interpreters <- df_disag %>% 
  pull(email) %>% 
  unique()

# All pairs
pairs <- combn(interpreters, 2, simplify = FALSE)

# Pairwise agreement rate
pairwise_agreement <- lapply(pairs, function(pair) {
  data_wide %>%
    select(all_of(c(pair[1], pair[2]))) %>%
    filter(!is.na(.[[1]]) & !is.na(.[[2]])) %>%
    summarise(
      interpreter_1  = pair[1],
      interpreter_2  = pair[2],
      n_pixels       = n(),
      agreement_rate = mean(.[[1]] == .[[2]])
    )
}) %>%
  bind_rows()

print(pairwise_agreement)
#+end_src

A low agreement rate for one interpreter across /all pairs/ is a red flag 🚩.

---

/2. 🎯 Leave-one-out Alpha/

Recalculate Krippendorff's Alpha by removing one interpreter at a time. If removing interpreter X /increases α significantly/, they are likely the problematic one :

#+begin_src r
# Alpha with all interpreters
alpha_full <- alpha  # calculated previously

# Alpha leaving one interpreter out
loo_alpha <- lapply(interpreters, function(interp) {
  
  mat_loo <- data_wide %>%
    select(-plotid, -sampleid, -all_of(interp)) %>%
    as.matrix()
  
  # Recalculate D_o
  do_pixel <- apply(mat_loo, 1, function(row) {
    vals <- na.omit(row)
    n <- length(vals)
    if (n < 2) return(NA)
    paires_desaccord <- sum(outer(vals, vals, "!=")) / 2
    paires_total     <- n * (n - 1) / 2
    paires_desaccord / paires_total
  })
  D_o_loo <- mean(do_pixel, na.rm = TRUE)
  
  # Recalculate D_e
  toutes_vals <- na.omit(as.vector(mat_loo))
  freq        <- table(toutes_vals) / length(toutes_vals)
  D_e_loo     <- 1 - sum(freq^2)
  
  alpha_loo <- 1 - (D_o_loo / D_e_loo)
  
  data.frame(
    removed_interpreter = interp,
    alpha               = round(alpha_loo, 4),
    alpha_change        = round(alpha_loo - alpha_full, 4)
  )
}) %>%
  bind_rows() %>%
  arrange(desc(alpha))

print(loo_alpha)
#+end_src

| good1@example.com | 0.59 | -0.02 |

Check if one interpreter systematically over- or under-classifies as "Forest" :

#+begin_src r
bias <- df_disag %>%
  filter(Classification != "NotInt") %>%
  group_by(email) %>%
  summarise(
    n_total       = n(),
    n_forest      = sum(Classification == "Forêt"),

    pct_notint    = round(100 * mean(Classification == "NotInt"), 1)
  ) %>%
  arrange(pct_forest)

print(bias)
#+end_src

A very different =pct_forest= from the others suggests a /systematic bias/ 🚩.
